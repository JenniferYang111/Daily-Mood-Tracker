# Daily Mood Tracker

A gentle space to check in with your mood and reflect on your day.

**Live website:** [Open Daily Mood Tracker](https://jenniferyang111.github.io/Daily-Mood-Tracker/)

Choose a mood, write an optional handwritten-style note, and save it with a paper-crumple animation. Start Over clears your current check-in while keeping previous entries. Saved entries stay in the same browser on the same device using localStorage.

## Project files

- `index.html` — page structure and accessible form controls.
- `styles.css` — responsive styling, handwriting font, and animation styles.
- `app.js` — saving animation, mood history, browser storage, and Start Over.
- `assets/` — animal illustrations and the bundled handwriting font and license.

Open `index.html` in a browser to preview the page, or use the live website above. GitHub Pages publishes updates from the root of the `main` branch.
